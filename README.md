# English Learning Platform — Etap 2

To jest rozwinięcie Prototypu 2: ten sam prosty interfejs, ale wspólna baza danych online przez Supabase.

## Co działa
- Classes
- Reading Lab
- Vocabulary
- Grammar
- Tests
- Results
- student join by room code + name
- wspólne dane nauczyciela i uczniów
- automatyczne wyniki testów

## Co trzeba zrobić przed uruchomieniem
1. Utworzyć darmowy projekt Supabase.
2. Uruchomić `supabase_schema.sql`.
3. Włączyć Anonymous Sign-Ins.
4. Utworzyć konto nauczyciela i dodać jego UUID do tabeli `teachers`.
5. Wpisać Project URL i publiczny anon/publishable key do `config.js`.
6. Wrzucić pliki na hosting.

Szczegółowa instrukcja jest w `DEPLOYMENT.md`.
